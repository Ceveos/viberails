# @viberails/types

Shared TypeScript type definitions for the [viberails](https://github.com/Ceveos/viberails) toolchain.

Exports core types used across all viberails packages: `ScanResult`, `ViberailsConfig`, `DetectedConvention`, `Confidence`, and more.

## Installation

```bash
npm install @viberails/types
```

## Usage

```typescript
import type { ScanResult, ViberailsConfig, Confidence } from '@viberails/types';
```

## Documentation

See the [main repository](https://github.com/Ceveos/viberails) for full documentation.
